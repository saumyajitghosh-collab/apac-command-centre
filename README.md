## Data labelling discipline

Every data point in every module carries one of four labels:

- **FACT** — sourced from a named publication, regulator or company disclosure
- **CALCULATED** — derived from sourced figures
- **ASSESSMENT** — analyst judgement, not sourced data
- **DATA GAP** — known gap requiring primary research

This label discipline is the core design principle: competitive intelligence is only useful when you know what's verified and what's inference.

## Design system

- **Aesthetic:** Navy-and-gold editorial — financial terminal meets magazine
- **Typography:** Fraunces (serif titles), Public Sans (body), IBM Plex Mono (labels/data)
- **Navigation:** Fixed sidebar with scroll-spy, J/K keyboard section hopping, gold progress bar
- **Interactive elements:** Expandable play cards, clickable market detail panels, segment engines, regulatory timelines, bar charts, heatmaps
- **Responsive:** Sidebar collapses on mobile; floating home button appears below 1080px

## Tech notes

- Fully self-contained static HTML — no build step, no framework, no server
- Only external dependency: Google Fonts (Fraunces, Public Sans, IBM Plex Mono)
- Each module is a standalone HTML file that can be shared independently
- Hosted on GitHub Pages — zero infrastructure cost
- Data compiled September 2026; regulatory and market figures move monthly — refresh before external use
